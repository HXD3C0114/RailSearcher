# Rail Searcher

一款装在安卓手机上的铁路数据查询小工具，随时查线路、车站、车次和机车车辆。

## 能查什么

| 功能 | 你会看到 |
|---|---|
| 线路 | 全线站点顺序、电报码、公里标，输入时自动联想线路名 |
| 车站 | 电报码、所属的各条线路以及在该线路上的公里标 |
| 车次 | 停站时刻表、累计里程、运行时长、担当单位、编组与交路 |
| 机车车辆 | 车号对应的车型、当前与历史配属段、收录照片数 |

## 顺手的小设计

- **结果可以点穿**：线路结果里的站名点一下就查该站；车站结果里的线路名点一下就看全线；车次结果里的站名也能直接查
- **导出 CSV**：线路站点、车站所属线路、车次时刻表都能一键存成表格文件
- **页面本地加载**：界面断网也能打开，查询时需要联网
- **意见反馈**：页面底部有入口，写下想法提交即可

## 怎么用

装好打开就能用，不用注册也不用登录。在输入框里填名字，点「查询」。

几个小提示：

- 站名原样填写，「站」「所」这类字不要删
- 线路名以联想列表里出现的写法为准
- 车次含 `/` 时照原样输入；成对车次只填其中一个也能查到

## 系统要求

Android 7.0 及以上，查询需要联网。

## 关于数据

线路、车站与时刻资料来自公开的铁路数据整理；机车车辆配属来自车迷拍摄记录，不是官方台账，仅供参考。部分车次没有担当、编组或交路信息，属正常情况。
